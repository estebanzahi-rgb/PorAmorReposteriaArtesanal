# /nuevo-producto

Crea la estructura completa para agregar un nuevo producto al catálogo.

## Uso

```
/nuevo-producto [nombre del producto]
```

## Qué hace

1. Solicita: nombre, categoría, descripción base, precio y si tiene variantes
2. Genera la descripción del producto usando el tono de marca (ver agente `contenido`)
3. Crea el archivo de datos del producto en la carpeta correspondiente
4. Sugiere la imagen placeholder y dimensiones recomendadas
