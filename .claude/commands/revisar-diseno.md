# /revisar-diseno

Revisa la consistencia visual del componente o página indicada.

## Uso

```
/revisar-diseno [ruta del archivo o nombre del componente]
```

## Qué hace

1. Analiza el componente contra la paleta de colores y tipografía definidas
2. Verifica que sea responsive
3. Verifica accesibilidad básica (contraste, alt text, roles ARIA)
4. Propone mejoras puntuales sin reescribir todo
